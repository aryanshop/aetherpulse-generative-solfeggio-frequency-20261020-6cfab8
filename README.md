# AetherPulse: Solfeggio & Binaural Sound Lab

AetherPulse is a browser-based acoustic wellness synthesizer and brainwave entrainment lab built entirely with vanilla JavaScript and the Web Audio API.

## Features

- **Solfeggio Tone Generator**: Synthesizes pure healing frequencies (396Hz, 417Hz, 528Hz, 639Hz, 741Hz, 852Hz, 963Hz) with adjustable waveforms and volumes.
- **Binaural Brainwave Entrainment**: Generates phase-shifted stereo frequencies to stimulate Delta, Theta, Alpha, and Beta brainwave states.
- **Cymatic Visualizer**: Real-time HTML5 Canvas visualizer rendering reactive sacred mandalas, harmonic waveforms, and particle fields synchronized to active audio frequencies.
- **Acoustic Presets**: Quick-load states like 'Deep Focus', 'Deep Sleep', 'Pineal Awakening', and 'Root Grounding'.
- **Meditation Timer**: Built-in stopwatch session timer to track meditation and relaxation intervals.

## Local Run Instructions

1. Download or clone all files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click 'Start Session' to activate the Web Audio engine.

## Technical Note
This project is fully self-contained with no external dependencies, web fonts, or network requests.
